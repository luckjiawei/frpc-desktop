### 🚀 Highlights

- 🔍 Redesigned log viewer: filter by level with per-level counts, search keywords with in-line highlighting, toggle line wrapping, copy the visible logs, and see how many lines are shown. The application log page and every instance's frpc / cloudflared log drawer share the same view.
- 🧭 Structured log parsing: timestamps and source locations (for example `service.go:123`) are separated from the message for all three log formats, so long frpc lines are easier to scan.
- 💬 Modern toasts: messages now use a neutral card surface with a typed icon, consistent rounding and a softer shadow in both light and dark themes.

### 🐛 Bug Fixes

- Fixed the hover background on the log toolbar buttons, which fell back to Element Plus's default fill.
- Resource usage now sums CPU and resident memory across the whole app process tree.
- Deleting an instance now stays deleted across restarts; empty instance and proxy views render correctly.
- Proxy list and config reads are scoped to the latest request, so a slow response can no longer overwrite fresh data.
- Pending log output can no longer recreate a log file after its instance was deleted.

### 🔄 Upgrading from 2.0.0

- Installs over the existing 2.0.0 app in place. Server settings, instances, proxies, desktop settings and downloaded frpc / cloudflared binaries are kept.
- No database schema changes in this release.
- Update checks still open the GitHub release page; installers are downloaded manually.
