### 🚀 Highlights

- 🧱 Rebuilt on Tauri 2 + Rust: installers are much smaller and memory usage is lower than the 1.x Electron builds.
- 🔀 Multiple instances: run several frpc tunnels to different frps servers at the same time, and switch between them without leaving the current page.
- ☁️ Cloudflare Tunnel: manage cloudflared instances next to your frpc instances. Paste the tunnel token (or the whole install command) from the Cloudflare dashboard, and download cloudflared on the Download page or point the instance at a local binary.
- 📊 New dashboard: a read-only overview of every instance, including running state, proxy counts, connection errors, and bulk start/stop.
- 🎨 Refreshed UI: light, dark, and system themes, a collapsible sidebar, copyable addresses, and a cleaner toolbar layout.
- 🗄️ Drawer configuration: edit each instance's config and view its logs in a side drawer without leaving the page.
- 🧾 Application log: app and process lifecycle events are now written to `main.log` alongside the existing per-instance logs.

### 🔄 Upgrading from 1.x

- Version 2.0 installs over the existing 1.x app and keeps your data directory in place: server settings, proxies, desktop settings, and downloaded frpc versions are preserved.
- Existing single-server configurations are migrated into a default instance (`id = "1"`) that cannot be deleted; all existing proxies belong to it, so nothing changes unless you create additional instances.
- Data still stored in the older NeDB format (1.2.6 and earlier) is imported automatically on first launch, and the original files are kept as `*.bak`.
- Frpc-Desktop does not install updates automatically: the in-app update check opens the GitHub release page, where you can download the 2.0 installer and install it over the existing app.

### 🐛 Bug Fixes

- Fixed window close behavior so the app reliably hides to the tray instead of leaving an unusable window behind.
- Fixed autostart registration and silent startup handling on all supported platforms.
- Fixed the frpc version download pipeline, including mirror handling and downloaded-version bookkeeping.
- Fixed the macOS build so a single universal installer works on both Apple Silicon and Intel Macs.
- The macOS dock icon is now hidden while the app is minimized to the tray and restored when the window is shown.

### ⚡ Performance & Internals

- Moved process management, downloads, database access, system integration, and tray behavior into the Rust backend; the webview now focuses on presentation and state.
- Replaced the Electron main/renderer IPC with a typed `ipc_send` command router and event channels.
- Kept SQLite persistence and the schema migration runner from 1.2.7, with multi-instance and Cloudflare Tunnel migrations (`004`, `005`) applied on upgrade.
- Added cross-platform CI builds (Linux, Windows, macOS) for the Tauri application.
