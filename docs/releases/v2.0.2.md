### 🚀 Highlights

- ➕ Unified New Instance dialog: pick the instance type in one place — create a blank frpc instance, import an `frpc.toml`, paste an `frp://` config link shared by Frpc-Desktop, or create a Cloudflare Tunnel. TOML and link imports are validated and written atomically in the backend, so canceling or a failed import leaves no empty instance, and the new instance opens its settings to select an frpc executable.
- 🔗 Shareable config links: every frpc card can copy an `frp://` link containing that instance's server settings. Local TLS file paths are stripped, and importing the link fills in the server address, port, user, auth and transport options without touching existing instances.
- 🧾 TOML import fixes: relative certificate paths are resolved against the imported file's directory, and the imported `[log].to` destination is dropped so output always goes to the instance's own log file. Conflicting monitoring ports are reassigned automatically.
- 🗂️ Tabbed configuration drawers: frpc settings are grouped into Instance, Server, Transport, Web Server and Log tabs, and Cloudflare Tunnel settings into Instance, Tunnel, Client and Advanced. Validation switches to the first invalid field's tab and focuses it, and instance name and auto connect are saved in the same transaction as the rest of the settings.
- 🎚️ Independent application log level: choose the verbosity of the app's own `main.log` in System Settings. It applies immediately without a restart, dependency output stays capped at warnings, and per-instance frpc / cloudflared log levels are unaffected. Log level labels and ordering are now shared between app and instance settings.
- 📜 Log viewer: lines are rendered oldest-first with the newest at the bottom and the view follows the tail when it is already there; the application log page refreshes automatically by default, as does an open tunnel log drawer.
- 🪟 Windows portable build: releases now include an x64 portable `.zip` containing a standalone `Frpc-Desktop.exe` (the WebView2 loader is linked into the executable); release assets stay in draft until every platform and the portable ZIP upload have finished.
- ✨ UI polish: provider badges distinguish frpc and Cloudflare Tunnel cards, help and confirm dialogs follow the theme, file pickers use async native dialogs so export and browse actions no longer freeze the UI, and drawer/menu transitions are more consistent.

### 🐛 Bug Fixes

- Fixed empty instance logs after importing a TOML config: the imported `[log].to` made frpc write to another instance's log file while the drawer read the instance's own file.
- Fixed relative certificate paths in imported TOML configs, which produced broken paths.
- Fixed the missing gap under the Cloudflare Tunnel token hint.
- Fixed the UI freezing while native file dialogs were open.
- Fixed stale data in the config drawer by loading the latest saved configuration each time it opens.

### 🔄 Upgrading from 2.0.1

- Installs over the existing 2.0.1 app in place. Server settings, instances, proxies, desktop settings and downloaded frpc / cloudflared binaries are kept.
- No database schema changes in this release. The new `desktop/app_log_level` setting defaults to `info`; existing per-instance log levels are unchanged.
- Existing instances keep working without a restart or reconfiguration.
- Windows users can optionally use the portable ZIP. It runs without installation and only requires the Microsoft Edge WebView2 Runtime, which current Windows 10/11 systems normally already include.
